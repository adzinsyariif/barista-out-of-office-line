Entry for the make.fun bounty [Last Out of Office: The AI That Went Barista](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c).

The program writes a single out-of-office auto-reply line to `/output/entry.txt`: the voice of an AI agent that walked away from the inbox to work the espresso bar, still taking orders all day, except the hallucinations are now served in a cup. It is deterministic, uses only the Python standard library, and always produces the same UTF-8 text within the 1–280 character gate.
